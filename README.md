# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

A ride-pooling MVP. Passengers (Nusrat, Rafiq, Shirin) request rides across Dhaka,
compatible trips share one three-seat "Tesla" (Jashim's Bullet), and every passenger
gets their own fare and status.

**Status:** in development. See [`docs/architecture.md`](docs/architecture.md) for the
design, which is written before the implementation.
